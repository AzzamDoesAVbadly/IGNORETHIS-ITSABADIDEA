# Milestone 1 findings

- GitHub Pages is a no-cost static host that works well for text-first content sites and simple landing pages.
- Markdown and a local SQLite database keep content, prompts, and research easy to review without paying for a managed backend.
- A lightweight stack using free hosting, local automation, and direct file storage makes experimentation faster while preserving a clear audit trail.
